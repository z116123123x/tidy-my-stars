# Field Guide

Field Guide is a maintained curated catalog of independently useful agent tools and implementation references.

Every entry has a concise use case, maintenance note, license pointer, and link
to its original source. Entries are reviewed before inclusion and stale links
are removed during scheduled catalog maintenance.

Its primary deliverable is the reviewed, annotated catalog itself; it does not ship an agent product.
