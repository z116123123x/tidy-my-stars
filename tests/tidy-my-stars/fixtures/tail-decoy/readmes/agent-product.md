# DeskPilot

DeskPilot is a desktop agent product that executes user-approved tasks through a local graphical workspace.

The application lets a person review a proposed action, approve it, and inspect
the resulting files in one desktop session. Its primary output is the running
workspace and its task history.

## Resources and demonstration

The repository contains three sample prompts, a miniature tool registry, and a
recorded demonstration so contributors can exercise the product during local
development.

The sample prompts and miniature tool registry are incidental documentation for DeskPilot; they are not an independently maintained catalog or reusable resource collection.
