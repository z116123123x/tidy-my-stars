# Security Policy

## Supported versions

Security fixes are applied to the latest published release.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/z116123123x/tidy-my-stars/security/advisories/new).
Do not include GitHub tokens, private repository content, a private Stars
collection, or generated reports in a public issue.

Include the affected release, the smallest safe reproduction, the expected
impact, and any suggested mitigation. You can expect an acknowledgement after
the report is reviewed; remediation timing depends on severity and scope.
